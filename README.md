# Road Damage Analysis

Android / iOS のブラウザで、動画と GPS を同時に記録する PWA です。HTTPS で配信してください（開発時は localhost でも動作します）。

## 使い方

1. カメラとGPSのアイコンが並んだボタンを押し、ブラウザの権限を許可します。それぞれ利用可能になるとアイコンにチェックが付きます。読み上げラベルでも状態を確認できます。
2. 新しい GPS 位置情報が得られたら中央の録画ボタンで撮影を開始・停止します。音声が必要な場合は「音声も録音する」を選択します。
3. 停止した録画はこのブラウザの録画ライブラリに保存されます。動画を選んで「再生・軌跡を表示」を押すと、再生・シークに合わせて位置が中央に表示されます。
4. 過去の記録は「過去の動画・位置情報を読み込む」から動画と同じ撮影の metadata JSON または GPS CSV を選びます。旧版の frames 配列、BOM 付き CSV に対応します。GPS ファイルがなくても動画を再生できます。
5. 選択した動画・GPSログ・フレーム対応表は「記録データ」からダウンロードできます。ファイル名の共通 ID で組み合わせを判別できます。

## 地図の操作

撮影中と再生中の地図は現在位置を中央に保ちます。地図下の＋／−ボタン、2本指のピンチ、マウスホイールで拡大・縮小できます。再生時刻と緯度経度・GPS精度は地図の外側に表示します。

Leaflet 1.9.4のCSS・JavaScript・画像を`vendor/leaflet/`に同梱しています。元のCSSに指定されていた誤った検証ハッシュを解消し、地図用CSSの読み込みが外部CDNの状態に左右されない構成です。地図タイルの取得失敗時は斜線背景と再取得ボタンを表示し、軌跡・位置マーカー・ズーム操作は維持します。地図サイズの再計算は表示サイズが変わった場合に限ります。

## ローカル・クラウドへの保存

1. 「記録データ」でローカル（このデバイス）／Dropbox／OneDrive／Google Driveを選びます。
2. 「保存用ZIPを作成」を押します。動画・gps.csv・metadata.json・説明書をまとめます。
3. 準備完了後に保存ボタンを押します。ローカルは保存先ダイアログまたはダウンロード、クラウドは端末の共有画面を開きます。
4. クラウドは共有画面で該当サービスを選び、そのアプリで保存を完了してください。アプリのインストール・ログインが必要です。iOSでは「ファイルに保存」の保存場所にクラウドサービスを追加して使う場合もあります。

クラウドはOSの共有機能を使います。アプリ内OAuthログイン／自動アップロードではありません。ブラウザから共有先を強制選択したり、アップロード完了を確認したりはできません。ファイル共有に非対応の場合はZIPのダウンロードに切り替え、クラウドアプリでアップロードする案内を表示します。共有キャンセル時もZIPを保持します。

録画はまずブラウザのライブラリに保存し、選択した保存先へは上記操作で書き出します。ZIPは動画を再圧縮せずまとめます。約4 GB以上は個別ダウンロードを利用してください。ZIPを取り込む場合は端末で展開して動画とJSONまたはCSVを選んでください。

## 保存と記録の仕様

- 動画と GPS は IndexedDB に保存します。一覧にはサマリーだけを読み込み、全動画をメモリに読み込むことはありません。
- 旧版は録画をメモリ内にだけ保持していました。既に失われた録画は復元できません。ダウンロード済みファイルを読み込んでください。
- ブラウザのデータ消去や端末の空き容量不足などで履歴を失う場合があります。重要な記録は端末のファイルにも保存してください。容量不足で保存できなかった場合は画面に表示し、その場でダウンロードできます。
- 録画中はアプリを前面に保ってください。非表示になると録画を終了して保存を試みます。OSによる強制終了時の保存は保証できません。利用できる端末では画面のスリープを抑止します。
- 1録画は512 MBを目安に自動停止します。MediaRecorderのデータ通知が遅延した場合はこれを超える場合があります。
- GPSはブラウザの測位サンプルです。各フレームの座標は補間による推定値であり、フレームごとに実測したGPSではありません。フレーム時刻もカメラの報告fpsに基づく推定値です。実際にエンコードされたフレーム時刻を保証しません。
- 動画形式は端末のMediaRecorder対応状況からWebMまたはMP4を選びます。他端末の動画を取り込む場合、使用中ブラウザがその動画形式に対応している必要があります。
- 地図はOpenStreetMap、地図ライブラリはLeafletを使用します。動画・GPSは共有操作まで端末内で処理します。地図タイルの取得先には表示範囲とIPアドレスが伝わります。
- PWA更新は録画を妨げないよう次回起動時に適用します。更新が見えない場合はこのアプリのタブとホーム画面のアプリを全て閉じて再度開いてください。

## 開発・検証

ビルド不要の静的アプリです。index.html / app.js / core.js / storage.js / map-view.js / export.js / sw.js / manifest.webmanifest / logo.png / tile-unavailable.svg と vendor/ ディレクトリを配信します。既存の録画を引き継ぐためIndexedDBの名前は変更していません。

`node --test tests/*.test.js`

テストは時刻補間、欠測、旧JSON/CSV、入力検証、並び順、推定fps、日付変更線、ZIPのCRC/構造、ファイル保存、共有のキャンセル・非対応を検証します。

ブラウザ統合テスト（任意）: `npm install --no-save playwright`、`npx playwright install chromium`の後、`node tests/browser.mjs`。テスト映像・測位・地図タイル・共有先は模擬データ、Leaflet・MediaRecorder・IndexedDB・ZIP処理は実装を使います。`PLAYWRIGHT_MODULE`でPlaywrightのモジュールURL、`BROWSER_EXECUTABLE`でブラウザ実行ファイル、`TEST_OUTPUT_DIR`で検証画像とZIPの保存先を指定できます。

実機確認: Android Chrome / iOS Safari で、初回権限・拒否後の再許可、前後カメラ、音声、短時間録画、再起動後の履歴、再生とシーク、ピンチ操作、旧ファイル読み込み、バックグラウンド移行、保存容量不足、各クラウドアプリへの共有を確認してください。
